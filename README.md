# Sistem Informasi Geografis (SIG)

Repository ini berisi proyek Sistem Informasi Geografis (SIG) yang digunakan untuk mengelola, menyimpan, dan menampilkan data spasial. Proyek ini memanfaatkan QGIS untuk proses pengolahan dan visualisasi peta, serta PostgreSQL/PostGIS melalui pgAdmin untuk pengelolaan database spasial.

## Tujuan Proyek
Proyek ini dibuat untuk mendukung analisis data geografis secara lebih terstruktur, terorganisir, dan efisien.

## Tools yang Digunakan
- QGIS — untuk pengolahan dan visualisasi data spasial
- PostgreSQL — sebagai sistem manajemen database
- PostGIS — ekstensi PostgreSQL untuk pengolahan data spasial
- pgAdmin — untuk mengelola database PostgreSQL/PostGIS
